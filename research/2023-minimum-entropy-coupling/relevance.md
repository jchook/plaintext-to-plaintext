# Perfectly Secure Steganography Using Minimum Entropy Coupling

ICLR 2023; arXiv author copy. Reviewed 2026-10-18.

Provides the coupling formulation: preserving the cover distribution while maximizing information about the message. Useful theoretical reference for the entropy limit and alternatives to interval coding.

Exact minimum-entropy coupling is computationally hard. Practical approximations and their decoding behavior must be distinguished from the ideal optimization.
