# Provable Secure Steganography Based on Adaptive Dynamic Sampling

USENIX Security 2026. Reviewed 2026-10-18.

Investigates a model API that accepts a seed without exposing full probabilities. Relevant if we want to work through a constrained serving API rather than a custom logits interface.

The API must reproduce samples for supplied seeds. The authors identify provider nondeterminism as a limitation, so this does not eliminate the need for controlled execution.
